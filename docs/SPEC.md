# Spark TV spec (reference)

The product and architecture reference. Decisions, current state, open items and milestones live in [SETUP.md](SETUP.md).

## What it is

Spark TV is a browser-based prototype of a TV platform home screen in the style of LG webOS or Google TV. It has content-forward rows that blend titles from many streaming services, plus app tiles for those services. It runs on a fixed 1920×1080 canvas and is driven entirely by Left/Right/Up/Down, OK and Back, so it works with a real TV remote through a FLIRC USB receiver that maps remote buttons to keyboard keys.

## Who it's for

- A public portfolio piece for the "Making" section of derekpcollins.com. It shows that Derek can build TV prototypes that run on a TV with a remote.
- A working user-research prototype. A hidden moderator panel lets a facilitator switch languages, module variants and scenarios mid-session.
- Source material for a later blog post about building TV prototypes, showing them on a TV, and connecting a remote with FLIRC.

## Behavior carried over from the original (as behavior, not code)

- **Vertical row motion:** on Down, the exiting row slides up and fades while the rows below move up. Up does the reverse. Heights are measured in one batch read and cached per page.
- **Fixed-cursor horizontal scroll:** the card strip moves while focus stays in its slot. Nothing wraps anywhere.
- **Per-row focus memory,** cleared when the page changes.
- **Row virtualization:** only the focused row and one row either side are live in the DOM.
- **Dimming:** regions without focus (header, hero, rows) dim to about 50%.
- **metadataLine:** an array of strings or typed items (text, badge, icon, image), with separators added automatically.
- **Locale switching** with a fallback chain: the active locale, then `en`, then the key itself.
- **Config-driven setting rows** (selector, toggle, info), now used by the moderator panel.
- **Video lifecycle:** `preload="none"`; `src` is set only when the video is visible; on exit, pause, remove `src` and call `load()`; never play video under an overlay.
- **Launch screen** with a configurable duration.

## Module contract

```ts
create(config, ctx) => {
  el: HTMLElement
  focus(entry?): void
  blur(): void
  handleKey(key): 'handled' | 'exit-up' | 'exit-down' | 'exit-left' | 'exit-right' | 'back'
  destroy(): void
}
```

- Each registration declares a `type`, its `variants` (`[{ id, label }]`), and an options schema (toggle or selector) that the moderator panel can render.
- Registries: `sections` (hero, row, banner), `cards`, `displayPages` (keyed by contentType + variant), `overlays`.
- The focus engine knows only the contract. Vertical order is the header followed by the page's sections. Overlays live on a stack: Back pops the top overlay and focus returns to where it was.
- State lives in one store with explicit setters. Moderator state (locale, variants, toggles, active preset) is kept separate from session state (focus, overlay stack).

## Data

- **`data/layout.json`** (hand-authored): pages, each made of sections. A row references a TMDB query (e.g. `trending/movie/week`, discover by provider), explicit TMDB IDs, or the Spark Free catalog. The sync script resolves queries to IDs.
- **`data/catalog.json`** (generated by `npm run sync`, committed): normalized titles with `en` and `es` text.

  ```ts
  Title {
    id, source: 'tmdb' | 'sparkfree', contentType: 'movie' | 'tv',
    title, overview, year, runtime | seasons, rating, genres,
    images { poster, backdrop, logo? }, providers[], metadataLine,
    video? { trailer, full }
  }
  ```

- **`data/sparkfree.json`** (hand-authored): the Blender films, each with title, synopsis, year, runtime, credits, license, image paths and R2 video paths (trailer clip and full film). Verify each film's license on its Blender Studio page and prefer films with sources of 1080p or better. If a film exists on TMDB, enrich it from there.
- **Video pipeline:** a script that cuts 30–60 second trailer clips from the downloaded sources with ffmpeg, encodes the trailer and full film to 1080p H.264 MP4, and uploads them to R2. All media paths resolve through one `ASSET_BASE_URL`.

## Home page v1 (top to bottom)

1. Header: wordmark, nav (Home, Movies, Shows, Spark Free), profile
2. Hero: Spark Free billboard with multiple slides
3. Apps row: the Spark Free tile first, then the real providers
4. Spark Free row
5. Continue Watching (mock progress)
6. Trending Now
7. Top 10 (numbered cards)
8. Rows by provider (e.g. Popular on Prime Video): whichever look best from the data
9. Spark Free promo banner (full width)
10. Credits banner, which opens the Credits screen

## Module catalog v1

- **Heroes:** A = full-bleed video billboard; B = static carousel.
- **Cards:** poster (2:3), landscape (16:9), continue-watching (with a progress bar), top-10 (numbered), app tile, banner.
- **Display Page:** one generic template per contentType (movie, tv), with a clearly marked placeholder region for Derek's designs. Variant slots A and B are ready.
- **Overlays:** Start screen, Launch, Display Page, Player, Credits, Moderator panel.

## Moderator panel v1

- **Opening it:** a key sequence (default: M pressed three times within 1.5 s; configurable so a remote button can be mapped through FLIRC), or the URL param `?moderator=1`. Back closes it.
- **Controls generated from the registries:** language; a variant for each registered slot (hero, each row's card type, Display Page template); module option toggles; launch sound on/off; skip launch screen; launch screen duration.
- **Presets:** `data/presets.json` defines named scenarios that set any combination of controls. One selection applies all of them.
- **Reset session:** returns to the start screen, clears focus memory and the overlay stack, then replays the launch on OK.
- **Persistence:** state persists in localStorage and is mirrored to URL params, so each condition can be bookmarked.
- **Info rows:** version, build, catalog snapshot date.
- **Look:** it sits outside the fiction and looks visibly different from the TV UI.

## Key map v1

| Input                 | Action                   |
| --------------------- | ------------------------ |
| Arrow keys            | Left / Right / Up / Down |
| Enter                 | OK                       |
| Escape, Backspace     | Back                     |
| MediaPlayPause, Space | Play/pause in the player |
| M ×3 within 1.5 s     | Open the moderator panel |

Document this map in the README for the FLIRC post, along with the Chrome autoplay flag that lets the launch sound play without the start screen.
